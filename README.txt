المزامنة التلقائية:
- الإجراء Sync anime library يعمل كل 6 ساعات: 03:17 و09:17 و15:17 و21:17 بتوقيت الأردن (00:17 و06:17 و12:17 و18:17 UTC). قد يتأخر البدء حسب ازدحام GitHub.
- GitHub يوفر جهاز Linux مؤقتاً لكل تشغيل؛ لا يلزم تشغيل الهاتف أو الكمبيوتر أو إدخال توكن شخصي. يستخدم الإجراء GITHUB_TOKEN المؤقت بصلاحية الكتابة لهذا المستودع فقط.
- يكفي إضافة {"animeUrl":"https://yalanime.com/anime/.../"} إلى anime في library.json. يملأ الاسم والصورة والحلقات ويحافظ على الروابط والبيانات الموجودة.
- يتم تحليل HTML فقط دون تشغيل إعلانات أو مشغلات الفيديو. بعض الروابط التي تعتمد على JavaScript قد لا تظهر.
- لا ينشئ commit عندما لا تتغير البيانات. يعيد قراءة المكتبة قبل الحفظ، ويحاول مجدداً عند تعارض النسخة، ولا يعيد أنمي حُذف أثناء التشغيل.
- تُحفظ النتائج الناجحة أولاً؛ الأخطاء أو النتائج الجزئية تجعل التشغيل يظهر فاشلاً مع ملخص في Actions حتى يمكن مراجعتها. تبقى البيانات السابقة محفوظة.
- حد الجمع 90 دقيقة وحد التشغيل 110 دقائق. الحد الفردي 300 حلقة أو 10 دقائق لكل أنمي. لا تتداخل تشغيلات المزامنة.
- للتشغيل اليدوي: Actions ← Sync anime library ← Run workflow. تشغيل أولي يبدأ عند تعديل كود المزامنة، أما تحديث library.json فلا ينشئ حلقة تشغيل متكررة.
- تشغيلات Linux القياسية في المستودعات العامة مجانية وفق سياسة GitHub الحالية. قد يعطل GitHub الجداول في المستودعات العامة بعد 60 يوماً دون نشاط؛ أعد تفعيل الإجراء من Actions عند الحاجة.
- للمطورين: npm ci ثم npm test. تجربة قراءة فقط: npm run sync -- --dry-run --limit=1.
- tools/yalanime-collector.js نسخة ثابتة من سكربت sync-anime-library.js في malqammaz/script-browser-scripts عند commit 727010b؛ حدّث النسخة مع الاختبارات عند تغيير محددات الموقع.

التنقل: الأنمي ← الحلقات ← روابط المشاهدة، والروابط تفتح في نفس الصفحة.
واجهة بيضاء، بحث، ترتيب بالاسم، وعرض الأنميات كبطاقات أو قائمة.
لا تظهر أزرار استيراد/تصدير JSON أو أعداد الحلقات والروابط.
زر «وضع علامة كمُشاهد» على كل أنمي يحفظ الحالة في Local Storage تحت المفتاح anime-library-watched-v1. اضغطه مرة ثانية لإلغاء العلامة. تُربط الحالة بالاسم الموحّد، وليس بترتيب الأنمي، وتبقى بعد تحديث الصفحة. الحفظ خاص بالمتصفح والموقع والجهاز الحالي؛ حذف بيانات الموقع يحذفه، ولا تتم مزامنته مع GitHub. عند فشل التخزين تظهر رسالة ولا تتغير الحالة ظاهرياً.
البيانات تُقرأ من library.json عند التشغيل عبر خادم، ما لم توجد مكتبة محلية محفوظة سابقاً (anime-library-v1). احتُفظ بالتوافق مع المكتبات المحلية القديمة. استخدم خادماً محلياً أو GitHub Pages لفتح الموقع.
لإفراغ المكتبة من GitHub، افتح Actions ثم Reset anime library ثم Run workflow. سيُحدّث هذا الإجراء library.json إلى {"anime": []} ويضيف التغيير إلى الفرع الذي تم اختياره.
التحقق: فحص JavaScript، وإضافة/إلغاء علامة المشاهدة في المتصفح وبقاؤها بعد إعادة تحميل الصفحة. لا يتداخل زر المشاهدة مع رابط فتح الأنمي.
