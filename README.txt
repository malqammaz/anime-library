عند فتح الموقع تُجلب أحدث نسخة من library.json في فرع main مباشرة من GitHub، حتى لو وُجدت نسخة محلية قديمة. تُستخدم النسخة المحلية مؤقتاً للعرض وعند تعذر الاتصال. تبقى علامات المشاهدة محفوظة بشكل مستقل. استخدم خادماً محلياً أو GitHub Pages لفتح الموقع.
